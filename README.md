# Сайт «Славянская Сталь»

Одностраничный сайт производства металлических бытовок и модульных конструкций
в Саратове. Сделан на чистом HTML, CSS и JavaScript — без сборки, зависимостей и
внешних библиотек.

## Что внутри

```
site/
├── index.html              — вся страница
├── assets/
│   ├── css/styles.css      — стили и адаптив
│   ├── js/app.js           — конструктор, расчёт цены, формы, галерея
│   ├── fonts/              — Manrope и Unbounded (локально)
│   └── img/                — фотографии работ
└── README.md
```

### Разделы страницы

1. Первый экран с ключевыми цифрами.
2. Комплектации «Эконом», «Стандарт», «Премиум».
3. **Конструктор**: тип постройки, размер, комплектация, опции.
   Цена пересчитывается сразу, есть визуальное превью, копирование расчёта
   и заявка в WhatsApp.
4. **Примеры работ** — три реальных фото с просмотром в лайтбоксе.
5. Типовые планировки бытовки и модульного дома.
6. Процесс производства, технология и «пирог стены».
7. Дополнительные услуги, FAQ.
8. **Контакты** — телефон, WhatsApp, форма заявки, адрес и схема.

## Как открыть

Достаточно открыть `index.html` двойным кликом — шрифты и скрипты локальные,
интернет не нужен.

Для корректной проверки перед публикацией лучше запустить локальный сервер:

```bash
cd site
python3 -m http.server 8000
```

и открыть <http://localhost:8000>.

## Публикация

Сайт статический, поэтому подойдёт любой хостинг статики:

- **GitHub Pages** — загрузить содержимое папки `site` в репозиторий и включить Pages.
- **Netlify / Vercel** — drag & drop папки `site`.
- **Обычный хостинг** — загрузить файлы по FTP в корень домена.

Никаких переменных окружения и сборки не требуется.

## Что можно быстро поменять

### Телефон и мессенджеры

Телефон встречается в `index.html` в ссылках `tel:+79271002324` и `wa.me/79271002324`.
В `assets/js/app.js` он задан константой:

```js
const PHONE = "79271002324";
```

Замените номер в обоих файлах. В `index.html` также есть предзаполненное
сообщение WhatsApp в блоке контактов.

### Цены и комплектации конструктора

Все данные — в объекте `TYPES` в начале `assets/js/app.js`:

- `sizes` — размеры и площадь;
- `trims` — комплектации, цена за м² (`perM2`) и что входит;
- `costs` — цены опций (окна, дверь, электрика, отделка, кровля, терраса);
- `DELIVERY_PRICE` — доставка и монтаж.

Цена модуля считается как `perM2 × площадь`, затем прибавляются опции
и доставка. Итог округляется до 100 ₽. Это **предварительная модель**:
перед публикацией проверьте цены и сроки, особенно для модульных домов.

### Тексты, адрес и режим работы

Редактируются напрямую в `index.html`. Адрес и часы приёма указаны как
«по предварительной договорённости» — уточните формулировку под себя.
Паспортные и другие личные данные из бизнес-плана на сайт не переносились.

### Фотографии

Лежат в `assets/img/`:

- `work-1.jpg` — бытовка на объекте (используется на первом экране и в галерее);
- `work-2.jpg` — фасад, профнастил;
- `work-3.jpg` — модуль на блоках.

Замените файлы с теми же именами или поправьте пути в `index.html`.
Рекомендуемый размер — от 1200 px по длинной стороне.

## Особенности реализации

- **Без бэкенда.** Формы не отправляют данные на сервер: они собирают текст
  заявки и открывают WhatsApp с готовым сообщением. Это удобно для быстрого
  запуска, но заявки не сохраняются в базе. Для полноценного приёма заявок
  можно подключить Formspree, CRM или собственный API.
- **Доступность.** Семантическая разметка, клавиатурная навигация, `aria`-атрибуты,
  видимый фокус, `prefers-reduced-motion`.
- **Адаптивность.** Контрольные ширины: 1440, 1024, 768, 390 px.
- **Шрифты** Manrope и Unbounded подключены локально (кириллица + латиница),
  поэтому сайт не зависит от Google Fonts.
- **Карта** — стилизованная схема, кнопка ведёт в Яндекс.Карты. Если нужен
  настоящий интерактивный виджет, вставьте iframe карты в блок `.map-card`.
